Splace — WordPress Developer Assessment

This repository contains a WordPress developer assessment built on a local MAMP environment. It includes a custom theme (wp-content/themes/splace-assessment) covering both the front-end and back-end tasks, plus a full database backup so the site can be reproduced locally.

What's included

  • A full WordPress installation configured for local development with MAMP.
  • A custom theme, splace-assessment, with:
    • A responsive navigation bar that folds into a menu button on smaller screens.
    • Three property cards showing prices, addresses, property details, status labels, and availability.
    • A review slider with six sample reviews — three visible on desktop, two on tablet, one on mobile — with arrow and dot navigation.
    • Font Awesome icons, Bootstrap, and the Open Sans font.
    • A custom splace_job post type with archive and single templates for the back-end task.
  • db-backup.sql — a mysqldump backup of the local db_splacefront database.
  • front-end-wordpress-assessment-guide.md — setup steps and a plain-language explanation of every theme file.

Setup

  1. Clone this repository into your MAMP web root.
  2. Start the MAMP servers, then open phpMyAdmin and create a database named db_splacefront.
  3. Import db-backup.sql into that database.
  4. Copy wp-config-sample.php to wp-config.php and set DB_NAME to db_splacefront, DB_USER / DB_PASSWORD to your MAMP credentials (default root / root).
  5. Open the local site URL shown by MAMP and sign in to the dashboard.
  6. Activate the splace-assessment theme under Appearance → Themes if it isn't already active.
  7. Visit the homepage to see the property cards and review slider, and /jobs/ for the back-end post type.
